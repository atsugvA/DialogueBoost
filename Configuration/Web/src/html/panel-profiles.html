Dialogue Boost

Lifts the centre channel, where speech sits, and leaves the rest of the mix alone. The result is written as a second audio track you pick in the player.

Applied to every layout that has a centre channel, 3.0 through 7.1, and every other channel is carried through untouched. A stereo source has no centre, so the voice is separated out of the pair instead.
Comma-separated, e.g. eng, spa. Empty means every candidate language.
Which code do I write?
The player opens on the boosted track instead of the source's own, so nobody has to pick it from the audio menu each time. Only one profile can hold this — switching it on here takes it off the others. A viewer whose Jellyfin account prefers a particular audio language still gets that language first.
